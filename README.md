# The Jackpot Is Not a Promise: Lottery Data Analysis with Power BI

## Project Overview

This project was developed as part of DSC 640 coursework at Bellevue University. It uses Microsoft Power BI to explore historical lottery winning numbers, number frequencies, game structures, multipliers, and jackpot odds.

The dashboard, titled **"The Jackpot Is Not a Promise,"** examines historical lottery patterns and illustrates the difference between perceived patterns and the mathematical randomness of lottery drawings.

The purpose is descriptive analysis and data visualization, not predicting future winning numbers.

## Business and Analytical Objectives

- Analyze historical winning-number frequencies across multiple lottery games.
- Compare lottery game structures and jackpot odds.
- Explore multiplier distributions and drawing patterns.
- Communicate findings through an interactive Power BI dashboard.
- Demonstrate how historical patterns can be misinterpreted as predictive signals.

## Data Sources

The project uses historical lottery drawing datasets for:

- Mega Millions — beginning in 2002
- Pick 10 — beginning in 1987
- Powerball — beginning in 2010

The uploaded CSV files contain 17,472 records in total. The Power BI dashboard displays 13,583 total drawings analyzed; this figure reflects the report's displayed calculation and has not been independently reconciled to the combined source-file count.

The datasets were obtained from publicly available lottery winning-number records.

## Key Analytical Insights

Historical lottery results can be examined for frequency differences and distribution patterns. However, past winning-number frequencies do not establish which numbers will appear in future independent drawings.

Jackpot odds also vary by lottery game structure. A larger jackpot does not necessarily mean a greater probability of winning.

This project emphasizes responsible interpretation of descriptive statistics and the importance of communicating uncertainty.

## Limitations

- Historical frequencies do not predict future independent lottery outcomes.
- Lottery games have different rules, number pools, and historical coverage periods.
- Comparisons across games should account for differences in drawing counts and game structures.
- The dashboard's displayed drawing count has not been independently reconciled to the total source records.
